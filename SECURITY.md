# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |
| < 0.1   | No        |

This repository is a private application at version `0.1.0`; only the current development line is
maintained. Security patches are released as part of the normal release order described in
[release order](docs/ops/release-sequence.md).

## Reporting a vulnerability

**Please do not** open public GitHub issues for security vulnerabilities.

Report a vulnerability through GitHub private vulnerability reporting on this repository:

1. Open the **Security** tab of `alawein/blackmalejournal` on GitHub.
2. Choose **Report a vulnerability**.
3. Send the report privately to the maintainers.

Include:

- Description and potential impact
- Steps to reproduce (proof of concept if safe)
- Affected versions or commits
- Your disclosure timeline preference

Maintainers aim to acknowledge within **48 business hours** and will coordinate remediation and
disclosure with you.

## Safe harbor

The maintainers of `alawein/blackmalejournal` support good-faith security research that complies
with this policy and the repository's terms of service. We will not pursue civil or criminal action
for research conducted in accordance with this policy; we may ask you to cease if activity risks user
data or service availability.

## Disclosure

We credit researchers who report valid issues **unless** anonymity is requested. Public disclosure is
coordinated after a fix is available.
